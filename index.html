Configuracion de API y Modelo
Groq: API gratuita en console.groq.com/keys → "Create API Key". Sin tarjeta. Limite: ~12,000 tokens/min con Llama 3.3 70B.
Gemini: API gratuita en aistudio.google.com/apikey → "Create API key". Sin tarjeta. Ventana de 1 millon de tokens. Ideal para documentos largos.
Groq API Key — Obtener gratis en console.groq.com/keys
Google Gemini API Key — Obtener gratis en aistudio.google.com/apikey
🌐 Conexión a leyes vigentes en línea
Autobúsqueda de leyes actualizadas — La IA consultará automáticamente fuentes oficiales (diputados.gob.mx, scjn.gob.mx, ordenjuridico.gob.mx, poderjudicialedomex.gob.mx y más) para obtener los artículos vigentes según el caso, incluyendo información pública del expediente electrónico.
¿Cómo obtener tu API Key y CX gratuitas?
1. Ve a Google Programmable Search y crea un motor que busque en estos sitios (copia y pega):
diputados.gob.mx, scjn.gob.mx, ordenjuridico.gob.mx, cdmx.gob.mx, poderjudicialedomex.gob.mx (para el Tribunal Superior de Justicia y expediente electrónico).
2. Copia el "ID del motor de búsqueda" (CX).
3. Activa la API de Custom Search en Google Cloud Console y genera una API Key.
4. Puedes hacer hasta 100 búsquedas/día gratis.
Si no configuras esto, la IA usará solo el texto legal que pegues manualmente en el recuadro de abajo.
📜 Leyes inyectadas manualmente (respaldo)
Si la búsqueda en línea falla o no tienes API Key, puedes pegar aquí los artículos que quieras que la IA use de forma fija. Se combinarán con los resultados de la búsqueda automática.

Modelo de IA
Groq API (rapido — api.groq.com)
Google Gemini API (gratis — aistudio.google.com)
Llama 3.3 70B (Groq): mejor calidad para redactar escritos. 12,000 tokens/min gratis.
Llama 3.1 8B (Groq): rapido, ideal para analizar documentos. 20,000 tokens/min gratis.
Gemini 2.5 Flash: excelente para analizar y redactar, ventana de 1 millon de tokens.
Gemini 2.5 Pro: el mas capaz de Google, razonamiento avanzado, gratis con limites.
Gemini 2.5 Flash-Lite: el mas rapido y con mayor limite gratuito (15 req/min, 1,000/dia).
Retirados por Groq: Mixtral 8x7B, Gemma2 9B, Llama 3.1 70B.
Llama 3.3 70B: mejor para redactar escritos juridicos completos. Llama 3.1 8B: ideal para analizar documentos (mayor limite de tokens). Llama 4 Scout: modelo mas reciente de Meta en Groq 2025. Los modelos Mixtral 8x7B, Gemma2 9B y Llama 3.1 70B fueron retirados por Groq.
